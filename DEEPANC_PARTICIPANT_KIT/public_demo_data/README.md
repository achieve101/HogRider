# 公开演示场景数据

本目录只包含一个固定的公开场景，用于让参赛者在提交前看到模型的真实闭环
降噪指标。它不是正式测试集，也不代表模型在正式测试集上的最终成绩。

## 文件含义

| 文件 | 符号 | 内容 |
|---|---:|---|
| `reference.wav` | \(x[t]\) | 48 kHz、单通道、15 秒车载参考信号 |
| `disturbance.wav` | \(d[t]\) | 与参考信号对应的耳侧期望噪声 |
| `secondary_path.npy` | \(s[k]\) | 公开的 1 号次级路径，1967 点因果 FIR |
| `manifest.json` | — | 场景版本、长度和文件 SHA-256 |

评测脚本逐采样取得模型输出 \(y[t]\)，经过公开次级路径得到抗噪声：

$$
a[t]
=
\sum_{k=0}^{L_s-1}s[k]y[t-k]
$$

误差麦克风处的残差为：

$$
e[t]=d[t]-a[t]
$$

如果提交的是反馈模型，脚本在时刻 \(t\) 向模型提供
\(x[t]\) 和 \(e[t-1]\)。第一个采样点的 \(e[-1]\) 固定为 0。

公开脚本从所选起点连续读取3.5秒：前0.5秒用于初始化，后3秒划分为六个
0.5秒窗口计算声学成绩。两个阶段之间模型与次级路径状态保持连续。

请通过工具包根目录的 `run_public_demo.py` 使用这些数据，不要自行改变信号
对齐、符号或卷积方向。公开演示数据不属于模型提交内容，不要复制进
`my_submission/`，也不要打入最终 ZIP。
